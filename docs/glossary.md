# Glossary

- **Agent** — an AI coding-agent CLI (Claude Code, Codex, Pi, OpenCode, Antigravity, Copilot, Crush, Grok, Oh My Pi, Ori). Castellan is harness-agnostic.
- **Bless broker** — the expansion-request flow: an agent asks to widen its envelope (egress, config-dir writes); the daemon gates the request behind a dbus nonce (un-forgeable by the agent), rate-limits to 3/session, and requires fp-toggle biometric for high-risk expansions. See commitment #10.
- **Canary credential** — a fake API key / OAuth token planted in the envelope, wired to a localhost honeypot listener. Using OR probing it is the trigger. Real credentials never enter the envelope (commitment #4), so any credential the agent can read is a canary by definition.
- **Castellan** — the warden of a castle. Holds the keys, governs who comes and goes, guards the walls, can lock down. The project name.
- **Envelope** — the Landlock + seccomp ruleset applied to a session at spawn. Defines the writable set, the network capability, the blocked syscalls. Irreversible mid-session (kernel guarantee).
- **Enforce mode** — envelope denies out-of-bounds writes. Default for fresh installs in Phase 1+.
- **Audit mode** — envelope logs out-of-bounds writes but does not deny. Default for upgraders in Phase 1. Lets us measure false-block rate before enforcing.
- **Event spine** — the per-session append-only `events.jsonl` log under `~/.local/state/castellan/sessions/<uuid>/`. Every event tagged `source: kernel` (truth) or `source: agent` (advisory).
- **Freezer** — cgroup v2 freezer (`cgroup.freeze`). Writing 1 freezes all processes in the cgroup at the kernel level (they can't even handle signals). Writing 0 thaws. Daemon-owned (commitment #1) so the agent cannot self-thaw.
- **Harness** — the CLI runtime that runs an agent (Claude Code, Codex CLI, Pi). Distinct from the model and from castellan.
- **HDC** — Hyperdimensional Computing. 10K-bit bipolar hypervectors (1.25KB packed). Used by sensor-hdc and cortex-rs. Castellan uses them for session fingerprints and fleet radar.
- **Hint plane** — the top plane of the architecture. Experimental, off-by-default, advisory-only. Sentinel and sec-commit-label live here.
- **Kill criterion** — the metric a phase must pass before advancing. Failure → reduced scope (audit-only, advisory-only), not hand-waving. See ROADMAP.md.
- **Landlock** — Linux Security Module (mainline since 5.13, network since 6.7/ABI v4). Unprivileged, path-based, irreversible mid-session, inherited by children. The envelope primitive.
- **Ledger** — the kernel-witnessed record of what a session wrote. Primary substrate: overlayfs upper layer. Fallback: inotify on allowed paths.
- **Omarchy** — DHH's Arch + Hyprland distro, basecamp/omarchy. The upstream target.
- **Overlayfs** — Linux stackable filesystem. Castellan mounts it over the project dir in a user namespace: lower = read-only real, upper = session writes. Undo = discard upper. Atomic, no race (commitment #2).
- **Placebo control** — a real fix must drop the danger_signal more than a neutral placeholder, or it is not evidence. The un-gameable positive trust signal. See proof-fixes, cert-evals.
- **ProofCertificate** — the cryptographic certificate a session ends with: stayed in bounds, didn't remove validation paths (relay-vuln), preserved config completeness (config-radar), passed placebo-controlled tests. Tamper-evident (agent-audit-trail), exportable (evidence-pack). Generated by the daemon as verifier, not by the agent as prover.
- **Proof-carrying** — from Necula's proof-carrying code (1990s). The agent is the prover; the daemon is the verifier. Castellan generalizes relay-vuln's ProofCertificate from "this code is vuln-free" to "this session was safe."
- **Scope** — the systemd user unit (`castellan-<uuid>.scope`) owning a session's process tree. Gives free process-tree enumeration and the cgroup v2 freezer.
- **seccomp BPF** — Linux syscall filter. Castellan uses an allowlist (not denylist) and blocks chmod/chown/utime, io_uring, ptrace, process_vm_readv (commitment #8).
- **Sentinel** — the regime-detection hint component. sensor-regime underneath. Off-by-default, advisory-only, synthetic-AUROC-only until a real-corpus gate passes.
- **Session** — one invocation of one harness on one project. Has a UUID, a scope, an envelope, an event spine, a ledger, and (eventually) a ProofCertificate.
- **Trust tier** — a per-project score in [0,100] mapping to expansion rights. Gates ONLY expansion (egress, config-dir writes), never the envelope floor. Cold start at tier 2. Ceiling at 100. Always-on deny-list regardless of tier (commitment #6).
- **Trust.db** — the single-writer SQLite store of per-project trust scores. Owned by the daemon.
- **Watcher** — harness-state-watcher. skein/carrion fingerprint baseline of `~/.claude/skills/`, `~/.codex/skills/`, `~/.pi/agent/skills/` at install. Delta = new skill/hook → notify + quarantine pending approval. Closes the persistence-vector hole Landlock can't.
