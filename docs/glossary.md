# Glossary

- **Agent** — an AI coding-agent CLI (Claude Code, Codex, Pi, OpenCode, Antigravity, Copilot, Crush, Grok, Oh My Pi, Ori). Castellan is harness-agnostic.
- **Bless broker** — the expansion-request flow: an agent asks to widen its envelope (network access, config-dir writes); the daemon records the request and rate-limits it (3 per session, 10 per project per day, 5 minutes between requests). Approval is human-only and gated on the caller's controlling terminal matching the session's launcher terminal (kernel-enforced, C32) — not on a secret nonce, which was fishable from the daemon journal and proves nothing. See commitment #10.
- **Canary credential** — a fake API key / OAuth token planted in the session scratch, wired to a localhost honeypot listener. Using OR probing it is the trigger. Real keys live in the daemon keyring outside every envelope (commitment #4), so any credential found inside the envelope is a decoy.
- **Castellan** — the warden of a castle. Holds the keys, governs who comes and goes, guards the walls, can lock down. The project name.
- **Derived host** — a destination the launcher adds to the network allowlist because it came from the harness's own default endpoint (or an `*_BASE_URL` in the launcher's environment), when the operator declared no allowlist. Named in the launch banner and written to the spine as `egress_derived`; `CASTELLAN_EGRESS_DEFAULTS=0` turns the tier off.
- **Envelope** — the Landlock + seccomp ruleset applied to a session at start. Defines the writable set, the network capability, the blocked syscalls. Irreversible mid-session (kernel guarantee).
- **Enforce mode** — the envelope denies out-of-bounds writes. **The default posture**; `--no-enforce` opts out loudly.
- **Debug mode** (formerly "audit mode") — the envelope logs out-of-bounds writes but does not deny, and installs no egress broker. `--no-enforce`; for debugging, and it produces the false-block-rate data.
- **Egress allowlist** — the set of destinations a session may reach off-machine. Sources, in precedence order: `--allow-host` flags, `CASTELLAN_EGRESS_ALLOW_HOSTS`, `egress.toml`, then derived hosts. The same resolved list feeds the kernel broker and the egress proxy.
- **Event spine** — the per-session append-only `events.jsonl` log under `~/.local/state/castellan/events/<uuid>.jsonl`. Every event tagged `source: kernel` (truth) or `source: agent` (advisory).
- **Freezer** — cgroup v2 freezer (`cgroup.freeze`). Writing 1 freezes all processes in the cgroup at the kernel level (they cannot even handle signals). Writing 0 thaws. The daemon freezes and thaws through its socket (agent callers are refused); the agent cannot self-thaw because the envelope denies cgroupfs writes (Landlock default-deny). Freeze is indefinite; `freeze --kill-after-m N` opts into a kill deadline.
- **Harness** — the CLI runtime that runs an agent (Claude Code, Codex CLI, Pi). Distinct from the model and from castellan.
- **HDC** — Hyperdimensional Computing. 10K-bit bipolar hypervectors (1.25KB packed). Used by sensor-hdc and cortex-rs. Castellan uses them for session fingerprints and radar.
- **Kill criterion** — the metric a phase must pass before advancing. Failure leads to a reduced scope (advisory-only), recorded, not hand-waved. See ROADMAP.md.
- **Landlock** — Linux Security Module (mainline since 5.13, network since 6.7/ABI v4). Unprivileged, path-based, irreversible mid-session, inherited by children. The envelope primitive.
- **Ledger** — the kernel-witnessed record of what a session wrote. Primary substrate: the overlayfs upper layer. Fallback: inotify on allowed paths.
- **Omarchy** — DHH's Arch + Hyprland distro, basecamp/omarchy. Where the desktop controls fit.
- **Overlayfs** — Linux stackable filesystem. Castellan mounts it over the project dir in a user namespace: lower = read-only real, upper = session writes. Undo = discard upper. Atomic, no race (commitment #2).
- **Pass-through** — the egress proxy's behavior for a host with no keyring entry: the agent's own `Authorization` header reaches the provider unchanged, so OAuth-first harnesses work on a fresh install. With a keyring entry bound to the host, the header is replaced by the saved credential instead. See `egress_inject`/`egress_deny` spine rows.
- **Placebo control** — a real fix must drop the danger_signal more than a neutral placeholder, or it is not evidence. The positive trust signal that cannot be gamed by a vacuous test.
- **ProofCertificate** — the JSON certificate a session can be issued at any time (`castellan cert`): an in-bounds verdict and counts, placebo-proof and test-rerun evidence, the spine hash-chain verdict, and an ed25519 signature when the daemon has a key. Quality labels STRONG/MODERATE/WEAK/NON-EVIDENTIAL. Assembled by the daemon as verifier, not by the agent as prover.
- **Proof-carrying** — from Necula's proof-carrying code (1990s). The agent is the prover; the daemon is the verifier. Castellan applies the pattern to sessions: the daemon assembles evidence the agent cannot forge.
- **Scope** — the systemd user cgroup (`castellan.slice/<uuid>.scope`) owning a session's process tree. Gives process-tree enumeration and the cgroup v2 freezer.
- **seccomp BPF** — Linux syscall filter. Castellan uses a **denylist with default-ALLOW** and blocks a fixed set (mount-family, ptrace, `process_vm_readv`, io_uring, chown/xattr families, module syscalls). `chmod`/`utime` are deliberately NOT blocked (the git and touch workloads need them). A real allowlist is deferred until a workload probe proves it survivable; `test/syscall-drift.sh` checks the denylist against the running kernel.
- **Sentinel** — the regime-detection idea from an earlier design. Not built; HV radar was built, then its kill criterion demoted it to advisory (`castellan radar`).
- **Session** — one invocation of one harness on one project. Has a UUID, a scope, an envelope, an event spine, a ledger, and (on request) a ProofCertificate.
- **Trust tier** — a per-project score in [0,100] mapping to expansion rights, stored in `trust.db`. Gates expansion only (network access, config-dir writes), never the envelope floor. Cold start at tier 2; a project with no trust record runs the strict profile for its first session (undo forced). Ceiling 100. Deny-list always applies regardless of tier (commitment #6).
- **Watcher** — harness-state fingerprinting: a baseline of the harness's skill/config dirs is taken at session start and diffed at session end. Drift (a new skill, hook, or poisoned config) is written to the spine as `harness_drift` and logged. It detects; it does not quarantine or block.
